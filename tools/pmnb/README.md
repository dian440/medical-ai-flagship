# Prevalence-matched null baseline (PMNB)

**在跨数据集性能排序中，先验匹配本身造成的排序扰动有多大？**

这是一个可独立使用的诊断工具。它回答的问题是：

> 如果若干数据集在待比较的指标上**完全一样**，
> 那么仅仅因为评估队列的类别先验不同，排序会被扰动到什么程度？

## 为什么要它

在医学影像 AI 里，跨数据集比较经常按报告性能给数据集排序，
并据此判断"哪个模型更好"。但我们测得：**即便三个数据集的校准水平被调到完全相同，
仅改变类别先验本身就会在 82–84% 的重采样中改变排序**。

这个量此前从未被报告。没有它，任何"排序反转"都无法判断是真信号还是噪声。

它与已知统计参考量处在同一条谱系上：
Hanley & McNeil（定义 AUC 的零分布）、DeLong（定义 AUC 差的零分布）、
Nichols & Holmes（置换零分布作为标准参照）、Naeini 等（定义 ECE）、
PROBAST / CLAIM（定义评估清单）。这些工作都不是"提出新方法"，
而是**定义了一个"在什么范围内算正常"的参照量**，此后所有做同类分析的论文都必须引用它们。

## 安装与使用

无需安装，仅依赖 numpy（scipy 可选，用于 p 值）。

```python
from prevalence_matched_null_baseline import pmnb

res = pmnb(
    datasets={
        "siteA": {"y": y_a, "score": s_a},   # y: 0/1 数组, score: 概率
        "siteB": {"y": y_b, "score": s_b},
        "siteC": {"y": y_c, "score": s_c},
    },
    metric="ece",        # "ece" | "auc" | "brier"
    n_reps=500,
    seed=20261104,
)

print(res.baseline_rate)    # 零基线：例如 0.83
print(res.observed_rate)    # 真实数据的排序改变率
print(res.exceeds)          # 观测是否超出基线
print(res.report())         # 完整可读报告
```

命令行自检：

```bash
python prevalence_matched_null_baseline.py --demo
```

## 三种基线构造

| 名称 | 含义 | 用途 |
|---|---|---|
| `identical` | 各库在待比较指标上**完全相同**（用合并池独立抽样） | **主基线**，最保守、最可比 |
| `independent` | 各库保留自身指标分布但独立抽样 | 参考 |
| `label_permutation` | 标签置换（模型无判别力） | 仅作参考，**不用于主判定**——该条件下排序结构本身高度偏斜 |

## 实现要点

- **观测与基线的真正差别**：两条路径**都是独立抽样**。
  观测路径把每个库按各自数据重采样到共同先验，保留各库自身的分布结构；
  基线路径则从一个共同分布（合并池或单库参照池）独立抽取。
  **基线的"独立"指的是其取值来自共同分布，而非"与观测的抽样方式不同"。**
  若观测改变率不超过基线，则该改变完全可由噪声解释。
- **目标先验** = 各库先验的中位数；**目标样本量** = 各库都能供出的最大规模
  （受最小少数类计数限制）。
- 指标无关：AUC / ECE / Brier 均可；排序方向自动处理（AUC 越大越好，其余越小越好）。
