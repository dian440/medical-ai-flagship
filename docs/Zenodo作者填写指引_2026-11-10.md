# Zenodo「添加作者」弹窗 · 逐字段填法

> 面向你现在打开的这个弹窗。照着填即可，不需要读任何统计内容。

---

## 一、最重要的三条

1. **添加顺序 = 论文作者顺序。** Zenodo 官方文档明确：
   "Creators are listed in the academic citation." —— 谁排第一，引用串里谁就是第一作者。
   所以**第一个添加的人要是论文的第一作者**。
2. **姓名必须用真实姓名。** GitHub 用户名 `dian440` 不是作者名，不能填进去。
   填错的话 DOI 记录里就带着错名字（虽然能改，但没必要）。
3. **姓氏和名字要分开填。** 官方文档：
   "The split is important for the automatic generation of citation strings."
   中文姓名 → 姓 = 姓，名字 = 名。例：姓「孙」、名「宇迪」。
   （Zenodo 会自动拼成 `Sun, Yudi` 这种引用格式）

---

## 二、逐字段填法

### ① 顶部的「人物 / 组织机构」
选 **人物**（已默认选中，不用动）。你填的是个人作者。

### ② 顶部的搜索框
`按姓名、识别码或隶属搜索人员……`

→ **留空，直接手工填下面三个框。**
（这个框搜的是 ORCID 数据库。你的两个老师多半不在里面，搜了也是白搜，
还容易搜到同名的陌生人。）

### ③ 姓氏（带红星，必填）
填你的姓，一个字。
- 例：`孙`

### ④ 名字
填你的名。
- 例：`宇迪`
- 如果是英文名/英文发表名，直接填英文（如 `Yudi Sun` → 姓 `Sun`、名 `Yudi`）

> 💡 **建议用英文发表的姓名形态**。Zenodo 是国际存档，引用会被全球读者看到；
> 而且你的论文是英文投稿，BMC 的作者署名也会是英文。
> 两边一致最省事。

### ⑤ 标识符（ORCID / ISNI / GND）
→ **留空，跳过。**

为什么：这里填的是**全球唯一身份标识**，需要提前注册 ORCID（orcid.org，免费，
但要邮箱验证，填表要 5–10 分钟）。**不是投稿必需项**，留空完全不影响发布。

> 💡 如果你以后想要（推荐，投稿时能加"ORCID iD"提升可信度）：
> 去 orcid.org 注册 → 把 `0000-0000-0000-0000` 这种格式粘进来。
> **注意别把 ORCID 和别的标识混了**——必须是 16 位数字的 ORCID。

### ⑥ 隶属关系
点开下拉，搜这几个词（**Zenodo 用 ROR 数据库自动补全，选带 ROR 的那条**）：

```
Zhongshan College of Dalian Medical University
```

→ 选中它（中文名「大连医科大学中山学院」）。
Zenodo 会自动带上 ROR 标识 `https://ror.org/02ajraz35`，审稿人和索引机构能自动识别。

**如果下拉里搜不到**（有时新界面搜索有延迟），就手打这一行：

```
School of Electronic Information Engineering, Zhongshan College of Dalian Medical University, Dalian, China
```

> 🔴 **注意别写成"大连医科大学"本部。**
> 你读的是**中山学院**，是独立法人单位，与本部是两所不同的法人。
> 审稿人会按 affiliation 核对，写错等于单位归属错误。

### ⑦ 职责
点开下拉，选：

| 谁 | 选这个 |
|---|---|
| 你本人 | `Researcher`（若你是通讯作者 → 选 `ContactPerson`） |
| 指导老师（参与署名） | `Supervisor` |

> 完整可选项共 23 个（contactperson / researcher / supervisor / projectmember /
> datacurator / editor / other …），我们只需要上面两个。

**要不要加老师？** 取决于一件事：

- 如果老师**已经是论文作者**（署名已定或在谈）→ 加到 **Creators**（就是这个弹窗）
- 如果只是给建议、**不在作者名单里** → 加到 **Contributors**（在表单的另一个区块）
  - 官方说明：**Creators 出现在引用串里，Contributors 不出现。**
  - 放错位置的后果：引用里会多出一个没在论文署名的人，或反过来论文里有的人没出现在引用里

### ⑧ 保存
- 只填你一个人 → 点 **保存**
- 还要加老师 → 点 **保存后添加另一个**，再弹一次窗填下一位

> 顺序提醒：先加**第一作者**，再加下一位。**不要**先加老师再加自己——
> 顺序错了要拖动重排。

---

## 三、填完之后

回主表单检查三处：

1. **作者列表顺序** = 论文作者顺序
2. **每个人下面挂的隶属关系** = Zhongshan College of Dalian Medical University
3. **标题 / Description / 关键词** 与 `docs/Zenodo_DOI操作指引_2026-11-10.md` §4 一致

然后：
- **保存草稿**（不发布）→ 可以随时回来改
- 确认无误 → **发布**

## 四、如果署名还没跟老师谈定

**这不阻塞你发布。**

Zenodo 官方原文：
> "You can edit the metadata (title, creators, etc) of a published record at any
> time. ... **This does not affect your DOI.**"

所以你可以：
1. 现在按**你 + 两位老师**的顺序填上（顺序是临时的也行），发布，拿到 DOI
2. 把 DOI 发我 → 我填进论文、解除投稿阻塞
3. 跟老师谈定后 → 回 Zenodo 记录页点 **Edit**，改 creators 的姓名和顺序 → **保存后 DOI 不变**

**但有一件事值得现在做**：**先跟两位老师打招呼说一声**"软件存档的作者栏会先填您二位，
顺序稍后按咱们定的调整"。这是礼节性通知，成本 1 分钟，也避免发布后要改。

```
人物 → 不搜 → 姓[孙] 名[宇迪] → 标识符留空
→ 隶属关系搜 "Zhongshan College of Dalian Medical University" 选中它
→ 职责 Researcher（老师选 Supervisor）
→ 保存后添加另一个 / 保存
```
