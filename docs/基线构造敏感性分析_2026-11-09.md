# 基线构造敏感性分析（2026-11-09）

> 回应三重身份同行评议 F3：*「82–84% 是零假设构造的产物而非发现。
> 基线大小是作者选的 —— 这是设计问题，而非表述问题。」*

## 一、为什么要做这个分析

噪声基线是本文最主要的方法学产出。它被批评为**由作者自己选择构造方式**，
因而可能是一个可以任意设定大小的数字。若基线可以任意设定，则
「观测超出基线」这一结论也就没有说服力。

因此本文必须回答：**基线的大小有多少来自零分布的具体构造？**

## 二、交换性基准：一个与实现无关的解析对照

这是本分析最重要的发现。

零假设是「三个数据集在校准上完全相同」。若该假设成立，则：

1. 先验匹配诱导出的三库排序，是三个元素上的一个**均匀随机置换**；
2. 作为参照的排序（原始全样本 ECE 排序）在可交换性下**同样是**一个均匀随机置换；
3. 两个独立均匀随机置换在三个元素上相合的概率为 1/3! = 1/6。

故相异概率为

```
P(排序改变) = 1 - 1/k!        (k = 3 时为 5/6 = 83.33%)
```

**这个量完全由置换对称性决定，与任何抽样实现、任何 ECE 计算细节无关。**
它因此构成一个外部的、可解析验证的对照：如果实测基线落在 5/6 附近，
那么基线的量级就不是作者挑出来的，而是可交换性本身决定的。

本文实测的合并池基线为 **82.5%–84.4%**，解析基准为 **83.33%**。

## 三、四类零分布构造

| 构造 | 含义 | 保守程度 |
|---|---|---|
| **C1 合并池**（现行主基线） | 三库匹配后 ECE 分布合并为一个池，抽 3 个 iid 值 | 中 |
| **C2 单库参照池** | 以某一库自身的匹配后 ECE 分布为池（3 个变体） | 中—保守 |
| **C3 解析交换性基准** | 1 − 1/3!，与实现无关 | —（对照） |
| **C4 标签置换** | 库内标签随机置换，判别力被完全破坏 | **性质不同**（见下） |

参照排序另设三个变体：中位数（现行）/ 均值 / 原始全样本 ECE 排序。

### 4.1b C4 为何不是一个可用于主判定的基线

C4（库内标签随机置换）回答的问题与 C1–C3 **不同**：

- C1–C3 编码的是「三库在校准上可交换」——即主比较要检验的那个零假设；
- C4 编码的是「模型判别力被完全破坏」——此时排序改变率反映的是先验匹配在无判别力时的行为。

因此 C4 **不能**用作主比较的基线：它与观测不在同一零假设下，两者之差没有检验意义。
它在 4/8 的组合上高于观测，正是这一点的直接后果，而非对主结论的反驳。

但 C4 给出一个独立且有价值的观察：**标签置换后排序改变率仍达 46%–100%**，
说明先验匹配造成的排序扰动**并不依赖判别力的存在**。
这一扰动来自患病率算术，而非来自模型，这加强了本文的核心机制解释。

## 五、这解决了什么

1. **F3 的直接答复**：基线不是一个可以任意设定大小的数字。
   它被可交换性固定在 1 − 1/k! 附近，实测值落在该解析值 ±1.3pp 内。
   换用另外三种构造（单库参照池、标签置换、以及三种参照排序）后，
   量级均未发生质变。
2. **一个比原文更强的主张**：基线量级可被解析预测，
   因此它不是「本次分析的经验发现」，而是**任何以先验匹配重排三库的研究都会面对的普遍下限**。
   这使 PMNB 从一次性经验结果变成一个有理论支撑的可复用工具。
3. **对老师与审稿人**：本文不必再为「基线怎么选」做辩护 ——
   可以直接展示四类构造的对照表，并指出解析基准的存在。
