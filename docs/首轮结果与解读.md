# 首轮跨数据集泛化性审计 · 结果与解读

> 生成：2026-10-30（脚本 `code/cross_dataset_eval.py`）
> 数据：NIH ChestXray14 `images_001`（4,999 张）+ Kermany chest-xray-classification（5,828 张）
> 模型：torchxrayvision `densenet121-res224-nih`（NIH 官方预训练权重，未做任何微调）
> 随机种子：20261030

---

## 1. 🔴 最重要的发现：**衰减方向是反的**

首轮（每类随机抽 400 张，seed=20261030）结果：

| 统一标签 | NIH（成人住院） | Kermany（儿童） | Δ | 相对变化 |
|---|---|---|---|---|
| PNEUMONIA | AUC 0.7901 | AUC 0.8026 | **+0.0125** | **+1.6%（性能"提升"）** |
| NORMAL | AUC 0.8160 | AUC 0.8640 | **+0.0480** | **+5.9%（性能"提升"）** |

**模型换到另一个数据集后，AUC 没有下降，反而略微上升。**

### 1.1 这不是好消息，是**假设被证伪**

本研究原本的命题是"跨数据集泛化会衰减"。**首轮数据不支持这个命题。**

必须面对的三种解释（不能挑对自己有利的那个）：

| 解释 | 说明 | 如何检验 |
|---|---|---|
| **A. Kermany 太简单** | 儿童胸片 + 单一二分类 + 图像质量更高 + 类间差异更明显，本来就比 NIH 的 14 类多标签容易得多 | **换第三个更难的数据集**（CheXpert / VinDr-CXR）看是否出现衰减 |
| **B. 派生分数掩盖了差异** | NORMAL 用 `1 - max(病种分数)` 派生，在 Kermany 上恰好更"干净" | 换用多标签 AUC（14 类）+ F1 + 校准误差（ECE）多指标并行 |
| **C. 样本量不足掩盖了真实衰减** | 每类 400 张，AUC 的 95% CI 约 ±0.04，+0.01/+0.05 的差异在统计上不显著 | **全量跑**（4,999 + 5,828），加 DeLong 检验 |

### 1.2 🔴 结论：**这不是"项目失败"，是"假设需要被更严格地检验"**

**这个结果如果写进论文，价值远超一个漂亮的衰减数字。**

- 如果只报"衰减 30%"：审稿人会问"你的对照集是不是太难/太简单"
- 报"**我们预期衰减，但首轮未观测到衰减，并给出三条可检验的解释路径**"：这是**方法学诚实性**的强证据，也是审稿人最看重的东西

**但前提是：必须把 A/B/C 三条都检验掉，不能只报有利的那条。**

## 2. 今天修掉的两个真 bug（记录下来，避免重犯）

### 2.1 Bug 1：`No Finding` 不是模型输出头 → NORMAL AUC 恒等于 0.5000

**现象**：首轮 NORMAL 的 AUC 在两个数据集上都**恰好 = 0.5000**（= 随机猜测）。

**根因**：`model.pathologies` 有 18 项，但**只有前 14 项是真实病种，后 4 项是空字符串占位**。
`No Finding` **根本不在输出里** → `prow.get("No Finding", 0.0)` 永远返回 0.0 → 所有样本的 NORMAL 分数完全相同 → AUC = 0.5。

**修复**：派生 NORMAL 分数 = `1 - max(14 个真实病种分数)`。
→ 这是一个**显式建模选择**，论文 Methods 里必须写明，不能当成"显然"。

**教训**：AUC 恰好等于 0.5 = 分数无方差 = 有 bug。**这个数值模式本身就是告警信号。**

### 2.2 Bug 2：取"排序后的前 N 张" = 系统性偏倚

**现象**：`os.listdir()` 返回的 NIH 文件是按患者 ID 排序的 → 前 N 张全部来自**少数几家医院**。

**为什么严重**：NIH ChestXray14 的原始 File List 是**按采集机构聚集**的。取前 400 张 = 只测了 1–2 家医院，**"跨机构泛化"这个命题根本没被检验**。

**修复**：改用 `np.random.default_rng(SEED).permutation()` 随机抽样，seed 固定（可复现）。

**教训**：任何"取前 N 条"的抽样，在按机构/按时间聚集的数据上都是**隐含的选择偏倚**。跨机构泛化研究必须随机抽样。

### 2.3 Bug 3：`xrv.datasets.normalize_transform` 在 1.5.7 中不存在

`AttributeError: module 'torchxrayvision.datasets' has no attribute 'normalize_transform'`
→ 改为照抄已跑通的 `demo_first_inference.py`：`normalize(img, 255)` → 取单通道 → `resize((1,224,224))`。

### 2.4 Bug 4：zip 内部三层嵌套

`images_001.zip` 解压后是 `images_001/images/*.png` + `images_001/__MACOSX/`。
→ 改为递归定位真正含 png 的目录（排除 `__MACOSX`）。实际拿到 **4,999 张**。

## 3. 标签口径（已落地到代码，见 `docs/数据获取方案.md` §3）

| 论文统一标签 | NIH 来源 | Kermany 来源 | 说明 |

---

## 4. 🔴 必须写进 Limitations 的三条（今天新增第 2、3 条）

1. **Kermany 是儿童胸片、NIH 是成人住院胸片** → 本次"差异"含「跨机构 + 跨人群」复合偏移，**不能单独归因为模型对临床部署的不可靠**。
2. **NORMAL 是派生分数**（`1 - max`），不是模型原生输出 → 与文献中直接用模型 NORMAL 头的研究**不可直接比较**。
3. **首轮为抽样结果**（每类 400 张），AUC 的 95% CI ≈ ±0.04 → **±0.05 以内的差异不显著**，不能宣称"性能提升"。

> —— 这依然是一个有价值且更少人做的命题。
