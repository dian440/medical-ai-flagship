### 2.1 ⚠️ 三个必须记住的技术细节

1. **hf-mirror 的 API 路径是 `/api/datasets/<repo>`，文件清单用 `siblings[].rfilename` 读** —— 直接猜路径会 404（`keremberke` 的 zip 在 `data/` 子目录下，不在根目录）。
2. **必须带完整浏览器 UA**：`Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/131.0.0.0`。裸 UA 会被 CDN 拦（返回 404），**不是站点故障**。
3. **本机 `http_proxy` 指向不支持 CONNECT 的本地代理（127.0.0.1:27885）**，会让探测结果失真。做可达性判断必须 `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy` 复测。
4. **Range 请求返回 206 实测通过** → 支持断点续传，2 GB 大文件中断不丢进度。

## 3. 🔴 标签口径映射（本项目最容易被审稿人抓的地方）

两个数据集的标注体系**不兼容**，AUC 无法直接算。必须预先定义映射，否则跨数据集比较不成立。

### 3.1 事实

| | NIH ChestXray14 | keremberke/chest-xray-classification |
|---|---|---|
| 任务形态 | 多标签（每张图可同时阳性多个） | **二值单标签** |
| 类别 | 14 类 + `No Finding` | `NORMAL` / `PNEUMONIA` |
| 样本量 | 112,120 张 / 30,805 患者 | train 4077 / test 582 / valid 1165 |
| 阳性定义 | `Finding Labels` 字符串内含疾病名 | 文件夹目录名 |
| 来源 | NIH（同一机构，住院正位片） | 儿童胸片数据集（Kermany et al.） |

### 3.2 映射方案（写入论文 Methods 的版本）

**采用"交集子集 + 预注册映射表"策略**：

| 论文中的统一标签 | NIH 侧来源 | keremberke 侧来源 | 备注 |
|---|---|---|---|
| `PNEUMONIA` | `Pneumonia`（14 类之一） | `PNEUMONIA` | **唯一一对一无歧义映射** |
| `NORMAL` | `No Finding` | `NORMAL` | NIH 的 `No Finding` 与 keremberke 的 `NORMAL` 语义不完全等价（NIH 的 normal 是"14 类全阴"，Kermany 的 normal 是"儿童健康胸片"），**必须在 Limitations 写明人群/设备域偏移** |
| 其余 12 类 | 直接用 | — | 仅在 NIH 单库内做多标签分析 |

**结论**：
- **跨数据集主比较指标 = `PNEUMONIA` 与 `NORMAL` 二分类的 AUC/F1 衰减**（两个数据集都有、可对齐、语义最接近）
- **跨数据集扩展分析（14 类）** 只在 NIH 内部做（多标签 AUC），作为"细粒度衰减地图"，不与 keremberke 比较
- **域偏移来源**必须写明：设备厂商不同（NIH 采集机构 vs Kermany 来源）、患者人群不同（成人住院 vs 儿童门诊）、图像后处理不同

### 3.3 🔴 这个设计的诚实性要求

Kermany 数据集是**儿童**胸片，NIH 是**成人**住院胸片。**域偏移大到可能让"P=0.85→0.70 的衰减"里有一半来自人群差异而非部署失配。**

→ **论文必须写**：本次审计测得的是「跨机构 + 跨人群复合偏移」，**不能单独归因为模型对临床部署的不可靠**。这一点写在 Limitations 第 1 条。
→ **这是本项目的方法论诚实底线，不写就是把噪声包装成发现。**
