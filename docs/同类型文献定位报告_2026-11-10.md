## 0. 一句话结论（先看这个）

**本论文的贡献不在"发现跨数据集会掉性能"，也不在"外部验证很重要"——这两件事中文生态已普遍接受（普刊层已有"跨中心+外部验证"的写法范式，且《放射学实践》2022 年已有一篇与我们结构几乎同构的英文文章）。**

**我们的贡献只落在"评测协议"这一层：把"排序翻转"从点估计现象升级为可检验的统计事实，并给出解析噪声基线 1 − 1/k!。**

这意味着：
- ❌ 不能把论文写成"跨数据集评估不可靠"的新发现 → 会被中文审稿人立刻以"已有大量同类研究"驳回
- ✅ 必须写成"已有工作观察到现象，但无人建立应当据以判断的基线" → 这才是不可辩护的新颖性
- ⚠️ 上述定位差异就是 2026-11-10 收到的三条独立 Agent 调研**唯一同时指向的结论**

## 4. C 层 · 中文期刊生态（从核心到普刊）

### 4.1 中文生态的通行写法（这是我们必须避开的陷阱）

**中文期刊已普遍接受"跨中心 + 外部验证"的重要性，且大量实证文章把"外部集 AUC 仍高"直接写成"模型鲁棒性好、泛化能力佳"。**

⚠️ **这是我们最危险的表述陷阱**：我们的数据显示 **7/7 显著差异全部指向外部集"更容易"**，且**零样本跨域 AUC 常常高于源域**。如果按中文通行写法叙述，会读成"模型泛化能力优秀"—— **与我们的结论完全相反**。

→ **写作纪律**：凡出现跨数据集 AUC 数字处，必须同时点明"该差异方向指向基准更弱而非模型更强"。论文 Discussion §4.4 已有此句（"A positive difference in discrimination on an external set is frequently evidence of a weaker benchmark rather than a stronger model"），**该句必须保留，且应在 Results 首次出现显著差异时即提示**。

### 4.2 三层期刊的真实写作深度

| 层级 | 代表刊物 | 真实深度 | 典型缺陷 |
|---|---|---|---|
| **A 核心/权威** | 中华放射学杂志 / 中华医学杂志 / 中国医学影像技术 / 临床放射学杂志 / 放射学杂志 | 部分文章纳入 **TRIPOD+AI**，报告 AUC+95%CI+校准曲线，少数做患病率分层 | 普遍**不做患病率匹配**、不区分同域/跨域、不建立噪声基线 |
| **B 科技核心** | 北京生物医学工程学报 / 中国医疗器械 / 中国医学装备 / 影像研究与医学应用 / CT理论与应用 | 多数为**单中心回顾性**；外部验证常**只做一次**（不是三库体系） | 三重身份评议已指出：**DCA 两两对比（6 次）** vs 我们单模型三域（3 次）——**不是我们的优势，勿写入论文** |
| **C 普刊** | 中国数字医学 / 中国当代医药 / 电脑知识与技术 / 信息与计算机 / 数字技术与应用 / 电脑编程技巧与维护 | 多数**不做外部验证**，仅内部测试集或不同参数下重复训练对比 | ①只报 AUC 不报校准 ②不做患病率控制 ③无置信区间 ④把"本院效果好"当泛化性证据 ⑤样本量普遍 <100 ⑥几乎无人做多中心/多数据集对照 |

### 4.3 中文生态里"我们可能被认为重复"的那一篇

**《放射学实践》2022, 37(1): 26-31 —— "基于深度学习的肺炎影像学筛查系统在低资源地区的应用"**（英文版：*Application of a deep learning-based pneumonia screening system in a low-resource setting*, 2022）

🔴 **这是中文生态里与我们结构最同构的一篇**：同样做**跨医院/跨数据集**测试、同样发现**泛化能力下降**、同样讨论**数据集和设备差异**的影响、同样把"跨机构验证"作为主要卖点。

**我们的差异化（投稿时必须写清）：**
1. 他们**只做外部测试**，不建立**跨数据集排名**的评估对象；
2. 他们**不做患病率控制**，因此无法区分"性能下降"是模型退化还是**队列患病率差异**；
3. 他们**不建立噪声基线**，因此无法判断"下降多少"是否超出测量噪声；
4. 他们的结论落在"**低资源地区仍可部署**"这一**应用/部署层面**——而我们的结论落在"**评测协议层面**"。

→ **这句话必须在 Introduction 或 Discussion 里明确写出**："我们的对象不是部署可行性，而是排名评估程序本身的可靠性。"
→ 这是本报告最重要的战术建议之一。

### 4.4 三条对中文生态的普遍批评（可写入 Discussion，是我们的差异化）

1. **只要 AUC 不看校准**：中文文献普遍把 AUC 当唯一指标，而本论文证明**排序翻转发生在校准维度而非 AUC 维度**——AUC 差异（最大 0.2211）远小于 ECE 差异（比值最大 5.39×）。
2. **不做患病率控制**：中文文献的跨数据集校准比较几乎不做患病率匹配，因而**系统性地把队列构成差异误读为模型优劣**。
3. **不做纳入规则敏感性**：中文文献几乎不检验"纳入规则变化会不会翻转结论"。我们做了 R1–R4 四种 NIH 纳入规则（超出基线 6/8–7/8），这是一个可强调的差异化。

## 5. 我们这次实际补上的方法学缺口（2026-11-10）

结合本次文献调研与代码审计，发现并修复了三处此前未记录的缺陷：

| # | 缺陷 | 严重性 | 修复 |
|---|---|---|---|
| 1 | **同域评估是训练集内重代入（resubstitution）**：`retrain_baseline_v2.py` 把训练样本也替换成评估队列，Table 5(c) 的 `0.9835` 是训练集 AUC 而非泛化 AUC | 🔴 极高（审稿人一眼可见，可致拒稿） | 训练池/评估队列彻底分离；同域改用 **5 折 out-of-fold 交叉预测**；跨域数字经回归校验与旧版一致 |
| 2 | **重训基线无不确定性量化**：只报点估计（"+13.8%"、"+1.6%"），无任何区间 | 🟠 高 | 补 **分层 bootstrap 95% CI**（AUC）与**配对 ΔAUC bootstrap CI**（同批样本重抽样），seed 20261103 / 2000 次 |
