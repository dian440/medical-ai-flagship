## 一、对"必须改的问题"的回应

全部接受。逐条确认与补充：

**1. DeLong "公开实现 bug" 表述与仓库不符 —— 接受，按 B 方案改写**
- 核实：`code/audit_delong.py` 仅 import csv/os/sys/numpy（第 27–31 行），审计对象是自研 `cross_dataset_eval.py`。**没有任何第三方实现被实际核实过。**
- 决策：摘要、§4.3、Cover Letter、贡献声明统一改为"我们修正了自己早期实现中的方差错误"（an error in our own initial implementation, identified by an internal audit with an independent bootstrap referee）。
- 删除 "whose published metadata does not correspond to the paper it is usually cited as" 一句——不可核实且易被读作对具体作者的指控。
- 数值结果不受影响（DeLong 方差式与 bootstrap 裁判三方一致），仅需改叙述归属。

**2. "reversed" 实为 "changed" —— 接受，全稿改口径**
- 核实：`code/prior_matched_ece.py:177` `flipped = (raw_rank != mat_rank)`，字段名 `rank_reversed` 名不符实。
- 决策：
  - 正文一律改用 "the ordering changed in all eight configurations (8/8)"；
  - 精确分解随文给出：完整反转 2/8、最优数据集改变 6/8、仅第 2/3 名互换 3/8；
  - 标题 "changes which dataset looks better" **保留**（6/8 最优库改变 + 8/8 排序改变足以支撑）；
  - 摘要 "reversed calibration ranking in all eight" 改为 "changed the calibration ranking in all eight, altering the best-performing dataset in six"；
  - 代码字段改名 `rank_changed`，JSON 同步，核验链重跑。

**3. p 值口径不成立 —— 接受，弃用 binomial 口径**
- 核实：`code/noise_baseline.py:211` `binomtest(changed, valid, b_same)` 将 500 次 bootstrap 重复当作 500 次独立伯努利试验，且把 b_same（4,000 次抽样的估计）当作固定真值。10⁻⁴² 量级不可信。
- 决策：改报"观测率 − 基线率 的差值 + Monte Carlo 95% CI"，另补数据集层面置换检验（n=8）作为稳健性（见 Q11）。
- **图 0/4 的 p ≤ 2.9×10⁻²² 与正文 5.7×10⁻²⁰、表 4 的 10⁻⁴² 三处不一致**：确认图是用旧结果画的。全部图件改为从最终版 JSON 重新生成，并加守卫：图注数值必须与当前 results JSON 一致。

**4. 图 4B 画错 —— 接受，重画**
- 核实：`figure4_noise_baseline.py:187` `ax2.scatter([sr], [sr])`、`:189` `ax2.scatter([sn], [sn])` —— x=y，所有点必然在对角线上。
- 修复：before 点 `scatter([sr], [sn])`（匹配前 ECE 为横轴、匹配后为纵轴）+ 对角参考线 y=x；after 点同理。
- 图注修正：最大收缩为 MIMIC_NH NORMAL（保留 23.9%），不是 MIMIC-CXR (noise-handled) PNEUMONIA（保留 77.5%，是 7 个收缩组中最小的）。

**5. 其余图表/正文不一致 —— 全部列入清稿清单**
- 图 1：5,828→5,824；136 张 OTHER 的画法改为"主分析计入 PNEUMONIA，严格敏感性分析中排除"。
- 图 2：补匹配后 ECE 数值，或改为只声称展示匹配前分布。
- §3.7 六组阈值改变计数：以 Table 5b 为准重写（4 个在 2 阈值、1 个在 1 阈值、1 个在 0 阈值）。
- §3.8 自相矛盾句：以中文版为准（仅第一个 ΔAUC 不含零）。
- §4.1 例外表述：改为"该配置的改变率未超过基线"，不是"排序未变"。
- §3.8 训练/评估域说反：65 例阳性在 NIH **评估集**，不在 Kermany 训练集；重写该句。
- 中英数字统一：以英文版为准，中文对照全量重核；摘要词数按实际重算。
- 措辞降级：删 "far more than discrimination"（不同尺度不可比）；"oppositely in four of eight" 改为精确分解；"discrimination did not fall" 改为 "no configuration showed a significant decrease; all seven significant differences favoured the external set"；重训段删 "degradation"（零样本在 Kermany 上高于 NIH，不构成退化）。
- 评审人指出的元问题成立：**既有守卫只覆盖数值与文本，不覆盖图注、跨语言一致性和算术一致性** → 新增三类守卫（图注-JSON 一致、中英数值对照、正文算术恒等式检查）。

**6. 两处论证弱点 —— 接受**
- 重采样 vs 重加权：评审人的批评正确——重加权到共同先验后，剩余 ECE 差异恰恰反映条件分数分布（即真实校准差异），二者对 ECE 渐近等价。决策：删掉这段对比（不作为区分 Akhtar 的论据），改为如实引用其贡献；若清稿时时间允许，补重加权对照实验作补充材料（见 Q8-①）。
- 169 vs 全样本：接受"样本量效应混淆"的质疑。决策：补"原始先验下同规模抽 169 张"的对照（见 Q8-③），在此之前正文对收缩幅度加 "at this matched sample size" 的限定。
