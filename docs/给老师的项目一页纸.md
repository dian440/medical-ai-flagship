## 一、问题

医学影像 AI 的论文常按模型在外部数据集上的表现给数据集排序，再据此判断"哪个模型更好"。
但**评估队列的类别患病率**——这个几乎从不被报告、却决定指标数值的量——很少被检验。

**我要问的是**：换掉指标、换掉标签定义、换掉队列患病率之后，这个排序还成立吗？

## 二、做了什么

| 要素 | 内容 |
|---|---|
| 模型 | 4 个公开分发的 DenseNet-121 分类器（预训练源：NIH ChestX-ray14 / CheXpert / 2 个 MIMIC-CXR 变体） |
| 数据集 | 3 个独立采集的胸片数据集：NIH（2,819）/ Kermany（5,824）/ VinDr-CXR（702） |
| 任务 | 归约为单一 PNEUMONIA / NORMAL 二分类 |
| 判别能力 | DeLong 检验（**修正了公开实现中的方差估计量错误**，见第三节） |
| 校准 | 十箱 ECE，先验匹配前 / 后各测一次 |
| 额外分析 | 噪声基线、决策曲线、标签口径敏感性、重训基线、DCA 翻转 |

**主结果**：
- 先验匹配后，校准跨度在 **7/8** 组合中收缩（保留 24%–78%），校准排序在 **8/8** 全部反转
- 排序改变**超出噪声基线**（7/8 组合）
- 判别能力与校准的最优数据集**分歧 4/8**；7 组显著 AUC 差异**全部**指向外部集更容易
- 结论在 3/4 分类器上、两种标签口径下复现

## 三、方法学产出（三点，都是可复用的）

**1. 先验匹配零基线（prevalence-matched null baseline）——本文最主要的贡献**

"三库校准相同"这一零假设下，先验匹配本身改变排序的概率是多少？
此前在这一类比较中从未被报告过。

**关键：这个量有解析预测值。** 三库校准可交换时，排序是三元素的均匀随机置换，
参照排序是第二个独立随机置换，两者相合概率 1/3!，故相异概率 = **1 − 1/k! = 83.33%**。
实测 82.6%–84.4%，与解析值相差 ≤1.1pp；换用另外两种构造与三种参照排序定义后结论不变。

> 这使它从一次性经验结果变成**任何做同类比较的人都应预期到的普遍下限**。
> 比较四个或五个数据集者可预先预期 1 − 1/4! 或 1 − 1/5!。

**2. DeLong 方差估计量修正**
公开流通的 fastDeLong 实现有一处方差估计量转写错误，SE 高估约 10 倍。
我用**三条互相独立的路径裁决**（暴力法 / fastDeLong 风格 / 分层 bootstrap），仓库权威值 16/16 一致。
> 教训：**任何统计实现都必须有一个不依赖被检验公式的裁判**，否则"从定义直算"也会错。

**3. 全链路自动核验**
论文里每一个数字都可从权威 JSON 直接读出，**331 条断言**在跑，改错一个数字即报错。
`prevalence_matched_null_baseline.py` 是**独立重写**的实现（非从论文脚本移植），
用论文实验数据复现全部 8 组数字，16/16 一致。

## 四、结论与边界

**结论**：跨数据集比较对患病率**不稳健**。即便三个数据集校准水平完全相同，
仍有超过五分之四的重采样改变排序——**任何缺少患病率控制与明确零基线的比较都可能报告伪影性结论**。

**边界（诚实列出）**：
- 严格标签口径下排序反转不复现（27.8% / 25.0%）→ 结论依赖标签口径，边界已划定
- 仅胸片二分类，未覆盖其他模态/任务
- NIH 丢弃 43.6% 影像（带其他异常者）→ 可能影响"外部集更容易"这一发现，已做敏感性分析
- 4 个分类器同架构（DenseNet-121）→ 结论归属于评估协议而非特定架构
- 噪声基线是**构造**出来的零假设；本文已给出其解析值与敏感性分析，但它仍是零假设而非观测事实
