# NIH 纳入规则敏感性分析（2026-11-09）

> 回应评审核心层：*「NIH 丢弃 43.6% 恰好丢弃带其他异常的影像——
> 可能自造了『外部集更容易』这个核心发现，须正面排除」*

## 一、为什么这个问题不能靠推理回答

主分析对 NIH 只纳入 2,819 张，其余 **2,180 张全部携带其余 12 类疾病标签**。
这些恰是「影像表现复杂、可能含肺炎」的病例。排除它们可能同时改变两件事：
**任务的难度**与**三库的患病率差距**。

而患病率一变，先验匹配的目标先验就变，跨度、排序、噪声基线**全部随之改变**。
因此本分析**重新推理了全部 4,999 张 NIH 影像**（4 个模型），并重算全部下游量。

## 二、口径一致性验证（分析可信的前提）

R1（现行规则）下重算出的 NIH AUC 必须与主分析**逐位一致**：

| 任务 | 本分析 | 主分析 | 一致 |
|---|---|---|---|
| PNEUMONIA | 0.722859 | 0.722859 | ✅ |
| NORMAL | 0.761812 | 0.761812 | ✅ |

NORMAL 分数的派生口径（1 − max(七个共同病种)）与主分析完全一致——
若误用 14 个病种全量，NORMAL 的语义就变了，分析将不可比。

## 三、四种规则

| 规则 | 被排除的 2,180 张如何处置 | 检验什么 |
|---|---|---|
| **R1_current_exclude** | 现行主分析：排除带其他 12 类标签的 2,180 张 | |
| **R2_other_as_negative** | 把被排除的 2,180 张在两个任务中都作为负类纳入 | |
| **R3_other_in_normal_only** | 被排除的 2,180 张仅加入 NORMAL 任务（作为负类） | |
| **R4_other_as_positive** | 被排除的 2,180 张在 PNEUMONIA 任务中作为正类（疑似肺炎宽口径） | |
