## 三、标签映射：统一到 NORMAL / PNEUMONIA 二分类

前两个数据集（NIH 14 类、Kermany 二值）的统一标签是 NORMAL / PNEUMONIA。第三个数据集必须落到同一口径，否则 AUC 无法比较。

### 3.1 全局标签分布（3000 张，实测）

| 类别 | 张数 |
|---|---|
| **NORMAL**（`No finding`） | **2051** |
| **PNEUMONIA**（肺部实变类，见下） | **276** |
| OTHER（其余病变，不参与二分类） | 673 |

OTHER 的构成：Calcification / Cardiomegaly / ILD / Pneumothorax / Pleural effusion / Pulmonary fibrosis / Pleural thickening / Nodule/Mass / Aortic enlargement / Other lesion / Mediastinal shift / Emphysema / Rib fracture / Clavicle fracture

### 3.2 两套映射口径（**都要报，主口径 + 敏感性分析**）

| 口径 | NORMAL | PNEUMONIA | 张数 | 用途 |
|---|---|---|---|---|
| **口径 A（宽松 · 主口径）** | `No finding` | Consolidation + Infiltration + Lung Opacity + Atelectasis + Lung cavity | 276 / 2051 | 与 NIH 的 "Infiltration"、Kermany 的 "Pneumonia" 语义最接近 |
| **口径 B（严格 · 敏感性分析）** | `No finding` | Consolidation + Infiltration only | 更少、更特异 | 检验结论是否依赖 "Lung Opacity" 这一宽泛类 |

> **为什么要两套口径**：审稿人一定会问"Lung Opacity 算不算肺炎？它包含很多非感染性阴影"。
> 提前准备两套，如果结论在两套下都成立，这个质疑就自动消解；如果结论只在宽松口径下成立，
> **说明我们自己的命题对标签定义敏感**——那必须如实写进 Limitations，而不是藏起来。

### 3.3 为什么不把 OTHER 塞进 NORMAL

这是本项目最容易被抓的一个坑。OTHER（673 张）里的 Calcification、Clavicle fracture、Mediastinal shift 等**不是正常胸片**，把它们算进 NORMAL 会：

1. **污染 NORMAL 类**——让"NORMAL"变成"无肺炎征象"，而不是"正常胸片"，两个数据集的 NORMAL 语义就不一致了；
2. **虚高 NORMAL 的 AUC**——模型只要不误报肺炎就能拿分，与 NIH 的 "No Finding" 完全不是一回事；
3. **让"性能不降反升"这个反常结果变得更不可解释**。

> **本项目的立场**：NORMAL = "无异常发现"（对标 NIH 的 No Finding），不是"不是肺炎"。
> 两个数据集的 NORMAL 必须语义严格对齐，否则跨数据集比较就是假的。

## 四、抽样与不平衡

VinDr 的 PNEUMONIA 只有 276 张，NORMAL 有 2051 张，**比例 1:7.4**；前两个数据集大致均衡。

**处理方式**（已写进 `download_vindr.py`）：

1. **分层随机抽样**：NORMAL 与 PNEUMONIA 各抽一半，固定 seed=20261031，保证可复现；
2. **实际抽到 NORMAL 600 + PNEUMONIA 276 = 876 张**（PNEUMONIA 全部用上，NORMAL 按需取 600）；
3. **AUC 对类别不平衡不敏感**（它只看排序），所以 276 张足以给出可用的 AUC 估计；
4. **但 ECE / F1 / DeLong 对不平衡敏感** → 因此：
   - ECE 报告时**必须同时报每箱样本量**（否则一个箱只有 3 个样本，均值毫无意义）；
   - F1 报 **F1@best-threshold + 敏感度 + 特异度**三个数，不只报 F1；
   - DeLong 检验在 276 vs 600 的样本上，检验力有限 → **结论以效应量 + 置信区间为主，p 值为辅**。

> ⚠️ **已记录的一个局限**：276 张是本研究的实际瓶颈。若后续要把 DeLong 做成主要证据，
> 需要找更多"肺炎样实变"的成人胸片——**但那属于扩样，不属于今天的关键路径**。

## 五、这个第三数据集解决什么问题

首轮结果（每类随机抽 400 张）：

| 统一标签 | NIH（成人住院·美国） | Kermany（儿童·二值） | Δ |
|---|---|---|---|
| PNEUMONIA | AUC 0.7901 | AUC 0.8026 | **+0.0125（不降反升）** |
| NORMAL | AUC 0.8160 | AUC 0.8640 | **+0.0480（不降反升）** |

三条待检验解释，VinDr 分别对应：

| 解释 | VinDr 能否检验 | 为什么 |
|---|---|---|
| (A) Kermany 太简单 | ✅ **能，且比 CheXpert 更合适** | VinDr 是**成人**（不像 Kermany 是儿童），人群与机构偏移独立于 Kermany 之外。若成人外部集上也测不出衰减，则"Kermany 太简单"这一解释基本排除 |
| (B) 派生的 NORMAL 分数掩盖了差异 | ✅ **能** | 口径 B（严格）下 NORMAL 的构成更纯，可检验结论是否依赖派生方式 |
| (C) 抽样量不足 | ✅ **能** | 全量 4999 + 5828 + 876 三库 + DeLong 检验，把"抽样噪声"这条排除掉 |

> **VinDr 的独特价值**：它同时提供"跨人群"（越南 vs 美国 vs 儿童）与"跨设备"（门诊 DR vs 住院设备）
> 的偏移，且**与前两个数据集在三个维度上都不同**——这是 CheXpert（也是美国成人住院）给不了的。
